# athena v1 (phases 0 to 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A chief-of-staff Claude session in a herdr "hq" space that launches visible worker Claude sessions in Linear-named worktrees, shows them as columns beside itself, and supervises them to merge-ready PRs.

**Architecture:** A Claude Code plugin repository (`~/Developer/athena`). Deterministic plumbing is a stdlib-only Python CLI, `bin/athena`. Judgment lives in two prompt files: `hq.md` (appended to the chief of staff) and `worker.md` (appended to every worker), plus the `athena` skill. Worker status comes from plugin hooks that write one JSON file per worker. herdr is driven only through its CLI.

**Tech Stack:** Python 3.9+ stdlib, POSIX sh, herdr 0.9.1 CLI, Claude Code 2.1.293 (`/goal`, `--settings`, SendMessage), `gh`.

**Spec:** `docs/decisions.md` and the blueprint artifact (https://claude.ai/artifact/TN2e6btFJV9uY4TGk1UZth). Research: `~/.claude/plans/athena/research/`.

## Global Constraints

- Python stdlib only, compatible with Python 3.9 (`/usr/bin/python3` on macOS).
- `ATHENA_STATE_DIR` (default `~/.local/state/athena`), `ATHENA_WORKTREE_ROOT` (default `~/Developer/.worktrees`), `ATHENA_HERDR` (default `herdr`), `ATHENA_HQ` (default `athena`), `ATHENA_MIN_COL` (default `70`), `ATHENA_MAX_WORKERS` (default `4`, hard cap `5`).
- Worker names match `[a-z][a-z0-9_-]{0,31}`; for Linear tickets the name is the lowercase id (`plt-4512`).
- Never touch the user's live herdr session in tests: automated tests use a fake herdr; integration runs use an isolated server (`env -i`, `XDG_CONFIG_HOME`/`XDG_STATE_HOME` in a short `/private/tmp` path, `--session athena-lab`).
- Hooks must exit 0 in every case and do nothing outside athena workers.
- No prompt text is written to state files except a 300-character summary of the worker's last message.
- Back up any user config before changing it (`~/.claude/plans/athena/backups/2026-10-07/`).

## Review Focus

1. A hook fires in one of the user's normal sessions (not an athena worker): it must be a no-op. Pinned in Task 4 (`test_hook_noop_outside_worker`).
2. `athena spawn` fails after the claim file is written (worktree create error, agent timeout): the claim must be removed, and the ledger must record `failed`, not `live`. Pinned in Task 5 (`test_spawn_failure_removes_claim`).
3. `athena retire` on a worktree with uncommitted or unpushed work: refuse without `--force`, and always write a backup ref first. Pinned in Task 9 (`test_retire_refuses_unpushed`).
4. The board rebuilds while the user is typing in a column: postpone the rebuild while any board column is focused. Pinned in Task 7 (`test_sync_postpones_when_column_focused`).
5. The main checkout is dirty or on another branch: preflight refuses and names the problem. Pinned in Task 3 (`test_preflight_refuses_feature_branch`).

### Task 3: git operations and quota gate (P0, P1)

**Files:** Create `athena_lib/gitops.py`, `athena_lib/quota.py`, `tests/test_gitops.py`, `tests/test_quota.py`.

**Interfaces:**
- `gitops.preflight(repo: Path, fetch=True, pull=True) -> dict` returns `{ok, branch, default_branch, dirty: [paths], behind, problems: [str]}`. Refuses when not on the default branch or tracked files are modified. Fast-forwards with `pull --ff-only` when clean.
- `gitops.choose_base(repo, branch) -> list[str]`: `[]` if a local branch exists, `["--base", "origin/<branch>"]` if only the remote has it, else `["--base", "origin/<default>"]`.

- `quota.five_hour_used(path=None) -> float | None` (None if the file is missing or older than 30 minutes); `quota.gate(threshold=85) -> tuple[bool, str]`.

- [x] Tests (temp repos with a bare origin): `test_preflight_ok_fast_forwards`, `test_preflight_refuses_feature_branch`, `test_preflight_refuses_dirty_tracked`, `test_choose_base_local_remote_default`, `test_unpushed_counts`, quota: `test_gate_blocks_above_threshold`, `test_gate_open_when_stale_or_missing`. ### Task 4: Worker hooks (P3, built early because spawn depends on the status contract)

**Files:** Create `athena_lib/hookstatus.py`, `hooks/worker-status`, `hooks/hooks.json`, `tests/test_hookstatus.py`.

**Interfaces:** `hookstatus.worker_name(env, cwd) -> str | None` (ATHENA_WORKER, else ledger lookup by worktree path). `hookstatus.apply(event: dict, name) -> dict` writes `workers/<name>.json` atomically: `{name, state, event, ts, summary, report}`. - [x] Tests: `test_hook_noop_outside_worker` (no ATHENA_WORKER, cwd outside root: no file written, exit 0), `test_stop_with_report_sets_done`, `test_blocked_report`, `test_permission_prompt_blocked`, `test_summary_truncated_to_300`, `test_garbage_stdin_exits_zero`. Implement. Commit.

### Task 5: Spawn (P1)

**Files:** Create `athena_lib/spawn.py`, `worker.md`, `tests/test_spawn.py`.

**Interfaces:** `spawn.spawn(repo, branch, name, brief_path, goal, linear=None, title=None, model="opus", effort="high", force=False) -> dict`.
Sequence: validate name, cap check (`ATHENA_MAX_WORKERS`, hard 5), quota gate, preflight, write claim, `worktree create --cwd <repo> --branch <b> [base] --path <p> --label "<NAME> <title>" --no-focus`, repo setup script if `repos/<repo>.setup` exists, write `briefs/<name>.md` and `settings/<name>.json` (`env` with ATHENA_WORKER, ATHENA_HQ, ATHENA_STATE_DIR, ATHENA_BRIEF; `crossSessionInbound: accept`; keepwarm plugins disabled), `agent start <name> --kind claude --pane <pane> --timeout 120000 -- --name <name> --model <m> --effort <e> --append-system-prompt-file worker.md --settings <file>`, remove claim, `agent prompt <name> <goal>`, `agent wait <name> --until working --until blocked`, `workspace report-metadata` tokens (`linear`, `athena=worker`), ledger `spawn` event with ws, pane, terminal, path, branch, repo.
On any failure after the claim: remove the claim, ledger `failed` with the reason, re-raise.

- [x] Tests with the fake herdr: `test_spawn_calls_in_order` (asserts argv sequence), `test_spawn_refuses_over_cap`, `test_spawn_refuses_when_quota_high`, `test_spawn_failure_removes_claim`. Implement. Commit.
